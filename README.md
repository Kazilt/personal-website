# anishkanduri.com

Personal site. Plain static HTML/CSS/JS, no build step, served via GitHub Pages.

- `index.html`: the whole site
- `assets/style.css`, `assets/script.js`: styles and the scroll-reveal effect
- `images/`: photos and screenshots
- `files/resume.pdf`: resume, linked from the site

To preview locally, just open `index.html` in a browser, or run any static file server from the repo root (e.g. `python3 -m http.server`).
